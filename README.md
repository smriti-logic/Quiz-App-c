# Quiz-App-c
## Overview
This is a simple quiz application developed in c that allows users to answer a series of questions. The app kjeeps track of the user's score and display the result 
at the end of the quiz. It is designed to help beginners practice basic programming concepts in C, including conditional statements, loops, and arrays.
---
## Features
-**Multiple Choice Questions**: Users will be presented with a set of multiple-choice questions.
-**Score Tracking**: The app tracks how many questions the users answers correctly.
-**User-Friendly Interface**: Simple and easy to understand interface for an engaging quiz experience.
-**Feedback**: The app provides immediate feedback on the user's answer after each question.
-**Final Score**: After all the questions the app shows the total score.
---
## Requirements
-**C Compiler**: A C compiler like GCC or any C IDE (code : blocks, Dev C++, etc).
-**Operating system** : The app runs on any operating system with a C compiler installed (Windows,Linux,macOS).
